# Images Folder

Add Urvashi's photos here!

## Instructions

1. Add your photos to this folder (e.g., `photo1.jpg`, `photo2.jpg`, etc.)
2. Update the `photos` array in `src/App.jsx` to reference your images:
   ```jsx
   const photos = [
     { src: '/images/photo1.jpg', alt: 'Memory 1', message: 'Beautiful moment 💖' },
     { src: '/images/photo2.jpg', alt: 'Memory 2' },
     // Add more...
   ];
   ```

## Supported Formats

- JPG/JPEG
- PNG
- WebP
- GIF

## Tips

- Use high-quality images for best results
- Recommended size: 800x800px or larger (square images work best for polaroid style)
- The first photo will appear in the landing section
- The last photo will appear in the final section
